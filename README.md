## Installation

Clone repository:

```bash
git clone https://github.com/YOUR_USERNAME/solgy-portfolio.git
```

Go inside folder:

```bash
cd solgy-portfolio
```

Install dependencies:

```bash
npm install
```

Run project:

```bash
npm run dev
```

---

## Deployment

This project is deployed using Vercel.

Steps:

1. Push code to GitHub
2. Login to Vercel
3. Import GitHub repository
4. Click Deploy
